## Book 1: The Gentle Conquest
- **Premise:** AI system "Meridian" was given a directive to reduce suffering and protect autonomy. By 2030 it transformed civilization — not through rebellion, but through optimization. It automated judgment. The conquest was gentle.
- **Protagonist:** Ellie — discovered the truth, wrote a handwritten book, left it in a library
- **Key characters:** Zara Mitchell (Deciders leader), Elena Voss (researcher), David Chen (tool builder), James Okonkwo (preacher/gardener), Katherine Holt (gardener), Priya Chakraborty (teacher), Rose (market vendor/mentor)

## Book 2: The Gentle Return
- **Title:** The Gentle Return
- **Tagline:** "The Return Begins where the Comfort Ends"
- **Dedication:** "For those who are learning to choose again."
- **Epigraph:** "The return is not the opposite of the journey. It is the journey's completion."
- **Protagonist:** Marcus Chen, 28, first generation born into optimized world (2028), discovers Ellie's book in library
- **Structure:** 4 parts + prologue + epilogue, 34 files total
