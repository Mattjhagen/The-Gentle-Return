# Launch Timeline

## Pre-Launch (2-3 weeks before)

| Task | Details |
|------|---------|
| Final proofread | Complete final pass of manuscript |
| eBook conversion | Convert to .epub and .mobi |
| Cover finalization | Ensure cover meets KDP specs |
| KDP setup | Upload manuscript and cover |
| Set preorder | Release date TBD |
| Set price | $4.99 (eBook) |
| Add keywords | Use keywords from keywords.md |
| Add categories | Use categories from categories.md |

## Week 1 (2 weeks before launch)

| Task | Details |
|------|---------|
| Social media teaser | Post cover reveal, excerpt, tagline |
| Email list | Send announcement to subscribers |
| ARC copies | Send to 10-20 early readers |
| Goodreads | Add book, enable reviews |
| Author website | Update with book page |

## Week 2 (1 week before launch)

| Task | Details |
|------|---------|
| Final push | Daily social posts |
| Blog posts | Write 2-3 articles about themes |
| Podcast outreach | Contact 5-10 podcasts |
| Price promo | Consider $0.99 launch week |
| Review push | Ask ARC readers to post reviews |

## Launch Day

| Task | Details |
|------|---------|
| Verify live | Check KDP, Amazon listing |
| Email blast | Send to full list |
| Social blitz | Post everywhere |
| Personal outreach | Text friends, family |
| Monitor | Watch for issues |

## Week 3 (post-launch)

| Task | Details |
|------|---------|
| Thank readers | Respond to reviews |
| Share milestones | Post sales numbers |
| Follow up | Contact podcasts, blogs |
| Plan next | Start Book 3? |

## Budget Estimates (Optional)

| Item | Cost |
|------|------|
| Newsletter promo (BookBub) | $100-500 |
| Social ads (Amazon/FB) | $50-200 |
| ARC copies | $0 (digital) |
| Website hosting | $0-10/month |

**Total:** $0-700 depending on ad spend

## Key Metrics to Track

- Preorder sales
- Day 1 sales
- Week 1 sales
- Review count
- Ranking position
