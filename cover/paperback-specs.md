## Cover Dimensions & Calculations (300 DPI)

Per Amazon KDP Cover Guidelines ([Amazon KDP Help G201953020](https://kdp.amazon.com/en_US/help/topic/G201953020)):

- **Spine Multiplier (Cream Paper):** 0.0025 inches / page
- **Spine Width:** 324 * 0.0025 in = 0.810 inches (242 pixels @ 300 DPI)
- **Bleed:** 0.125 inches (38 pixels) on all 4 outer edges
- **Total Cover Width:** 0.125" (bleed) + 6.0" (back) + 0.810" (spine) + 6.0" (front) + 0.125" (bleed) = 13.060 inches (**3,918 pixels**)
- **Total Cover Height:** 0.125" (bleed) + 9.0" (height) + 0.125" (bleed) = 9.250 inches (**2,775 pixels**)
- **Resolution:** 300 DPI
- **Color Profile:** RGB / CMYK Compatible
